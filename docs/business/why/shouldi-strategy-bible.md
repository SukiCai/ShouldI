# 1. Company Identity

ShouldI is building the world's first **Judgment Intelligence** platform.

Not an AI chatbot.

Not an advice app.

Not a productivity tool.

Not a therapist.

Not a social network.

ShouldI exists to help people continuously improve judgment throughout their lives.

* how they think

# 10. Decision DNA

Decision DNA is the user's evolving judgment model.

It is NOT simply memory.

It includes:

* decision history
* recurring patterns
* values
* priorities
* risk tolerance
* planning habits
* confidence calibration
* recurring blind spots
* emotional triggers
* learning trajectory

Decision DNA should become the most valuable asset inside the platform.

# 24. Internal Decision Filter

Before building any feature, ask:

1. Does this improve judgment?
2. Does it strengthen Decision DNA?
3. Does it increase long-term retention?
4. Does it make ShouldI harder to replace?
5. Does it support our category?
6. Would users become better decision-makers because of it?
7. If ChatGPT adds this tomorrow, would we still have an advantage?

If the answer to most questions is "no," the feature should not be built.

# 32. Decision Framework Library

ShouldI's long-term leverage is not model novelty; it is structured reasoning assets.

Core framework families to institutionalize:

* Career: BATNA, expected value, regret minimization, opportunity cost
* Investing: risk-adjusted return, downside analysis, Kelly-style sizing constraints
* Relationships: needs/conflict mapping, communication and compatibility frameworks
* Entrepreneurship: expected utility, scenario planning, asymmetric upside/risk
* Life planning: values hierarchy, constraint prioritization, time-horizon tradeoffs

Design requirement:

Every major decision domain should map to explicit, testable framework templates.
